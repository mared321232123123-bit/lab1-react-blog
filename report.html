Лабораторная работа № 1

Блог на React

Выполнил(а) _________________________ · Группа __________

Цель

Собрать блог на Vite и React из переиспользуемых компонентов, применить CSS-модули и сохранить проект в Git.

Ход работы

Header получает количество статей через props, а навигация выделена в Nav со своим CSS-модулем. ArticleList перебирает массив из articles.js и передаёт каждую запись в ArticleCard. Ключ карточки берётся из id. Обложки сделаны локальными SVG.

Flexbox переносит карточки при уменьшении ширины. На широком экране помещаются четыре карточки, на меньших экранах — три, две или одна. В итоговой версии восемь статей. История проекта включена в history.bundle.

Результат проверки

В браузере обнаружено восемь карточек. При ширине 1120 px первые четыре находятся в одной строке, а при 390 px вторая карточка переносится на следующую строку.

Воспроизведение

Распакуйте архив, выполните npm.cmd ci и npm.cmd run dev из папки с package.json. Откройте адрес, указанный Vite в терминале. Откройте «Блог на React» и сузьте окно браузера. Счётчик в шапке соответствует числу карточек.
